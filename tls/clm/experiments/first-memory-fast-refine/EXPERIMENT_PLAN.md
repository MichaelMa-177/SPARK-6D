# 首帧慢建模、后续快精修：最小有效性实验

用户已授权CLM3（ssh52699，有4090）实施；CLM2无卡，不启动GPU任务。复用现有SAM3D、PyTorch、BOP和几何函数，不改旧项目/权重/结果，不复制大模型。CLM3数据盘约3.2GB余量，本轮新增产物限制约500MB。

固定对象obj15钻头。场景50/54用于开发训练，59全部75个采样帧用于开发验证（已长期用于本项目开发，不称独立benchmark/未见物体）。数据是稀疏采样帧，真实frame ID单列，不冒充连续30Hz视频。59首帧000001必须复用人工mask/click 7f37ebe6a09819a6，核验RGB/depth/camera/mask SHA；后续不输入GT mask/pose、旧预测或CAD。训练可用50/54的GT mask/pose监督，训练首帧GT参考明确只属于训练，不混作人工点击评测。

首帧：CLM3重新运行冻结SS1/DINO518，RGB-D pointmap绕过单目深度估计；保存真实[1,4096,8]latent、layout和直接SS occupancy。按官方坐标变换得到预测几何prior，原始latent不可变。各训练序列也仅在首帧生成prior。提取256个实测RGB-XYZ锚点＋96个生成几何prior供轻量头使用，缓存K/V；未测背面不当GT。首帧mask推理/人类点击不计作本轮网络延迟。

后续：只从上一状态投影得到ROI，128×128轻量RGB-XYZ CNN→1024个当前query；soft correspondence＋no-match/confidence→加权一次刚体SVD。固定两轮局部修正，不用ICP、外部位姿、每帧SAM/DINO/SS生成或SGD。此128是新训练轻量网络的ROI，不是把冻结DINO缩到128。首帧物体坐标取第一相机轴、实测中心为原点；GT只在预测之后用一次固定首帧规范比较相对轨迹，不逐帧对齐。

训练预算先固定800步描述子/目标性监督＋400步带位姿扰动的精修监督（seed0，batch4）；保存last、best内部监督loss和阶段ckpt，不按scene59 GT挑最优。每100步sanity：loss有限、描述子命中/正例数量和GT匹配几何上限；梯度/有限性检查。若训练实现错误则修复后保留失败记录；质量不理想如实报告，不把运行通过视为定位成功。

先测冻结首帧记忆，主要对照：无生成prior、打乱首帧外观描述子、无记忆修正（仅上一状态）及完整记忆。逐帧重新编码和对应。只有冻结版达到开发门槛（平移中位≤10mm、旋转中位≤5°，并检查尾部和视频漂移）才尝试只写可靠新观测的小容量记忆；否则停留在冻结版诊断，不用写入掩盖错误。

精度：记录逐帧平移/旋转、可见表面对齐、对应命中及目标性，按全部75帧报告，不只挑成功片段；无背面GT不评完整形状正确性。性能：首帧重建与参考特征初始化单列；预热后丢弃全部状态，真实首帧重新初始化，稳态分别测已解码RGB-D→CPU pose和PNG→pose，禁用绘图/导出/GT评分计时。P50/P95/P99/max和最慢原frame ID；目标计算侧10–20ms，但不是已实现承诺。不能将丢失后prediction-only计时冒充成功精修。

验收：模型每环节数学测试＋真实精度对照＋视频/逐帧延迟曲线；产物与权重本地备份，服务器仍在线、不关闭或删除用户文件。启动按marker、真实进程和GPU验证；锁防并发，epoch/阶段last可恢复，结束DONE与exit-code单列。

2026-10-19 首轮完成后的受限诊断扩展：原版冻结记忆未过旋转门槛；GT当前位姿起点仍被精修拉偏约24.5°，但同一记忆的GT 3D对应上限为1.59mm/0.64°。因此固定last.pt，不重训，比较两组预先列定空间尺度（25→10mm、15→7.5mm）与原50→25mm；分别测完整/无生成记忆，全部报告。此为scene59开发参数消融，不按其结果宣称独立测试泛化或新SOTA；仍不启动增量写入。
