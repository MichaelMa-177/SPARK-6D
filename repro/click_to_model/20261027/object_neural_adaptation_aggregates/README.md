# Actual private translation-head adaptation: mixed error changes and added cost

One synthetic continuous-visible stream was run with and without the private 1,539-parameter translation head. Each actual arm contains **180 inputs / 179 tracking frames**, with initialization separate. The actual initialization pose is byte-identical; **177/179** tracking poses differ. Both arms retain **177 target / 2 neither / 0 unknown** tracking associations. All trust flags remain false; no explicit abstention was reported and verified risk is null.

Across all 179 tracking frames, mean target **ADD worsens from 2.662753 to 2.677744 mm**, and **MSSD worsens from 4.207945 to 4.233864 mm**. Mean normalized MSPD improves slightly, **2.543831 to 2.538584 px**. ADD decreases on 150 frames, increases on 27, and is exactly equal on 2; larger regressions outweigh many tiny decreases in the mean. Exact signs are descriptive, not a significance test.

The full fixed threshold matrix includes regressions and gains: MSSD < 0.15D **175→174**, MSPD < 10 px **173→172**, MSPD < 15 px **178→179**. MSPD < 5 px stays **168/179**, but one correct→wrong and one wrong→correct transition cancel. All 42 initialization/tracking paired tables and all 336 target/distractor qualified/verified summary rows are retained. Continuous errors are broken down by the same fixed occlusion phases, without filtering invisible or difficult frames.

Actual execution records **161 tentative updates and 18 resets**. Final-callback replay finds nonzero private-versus-original AMP output on **160/179** frames, and the selected AMP output exactly matches the actual saved output on all 179. This confirms a real numerical intervention, not effective accuracy improvement. Only the final callback has saved head features; within-frame version constancy of earlier callbacks relies on the frozen observer/assertions and callback counts. Tracking refinement callbacks total 268 in both arms, with 2 frames changing their iteration count.

Instrumented tracking time increases **15.504→22.283 s** (tracking FPS **11.546→8.033**); initialization is **16.102→14.113 s**, and parent wall **40.650→45.344 s**. Recorded adaptation work is **6.805835 s**, already contained in tracking time. Scopes overlap and must not be added. Sequential single runs do not establish a general runtime or accuracy effect.

The adaptation parent and child remain **failed**, with original parent **exit 1**. A separate exact raw recovery verified the complete 180/179 trajectory after classifying four cache reads blocked before open; source fallback was separately checked. This is a narrow recovery, not permission to ignore arbitrary failed runs. The dense helper lacked original exec-origin telemetry, so its evidence is the pinned pre-import source check, caller and CPU importer replay.

Earlier two-frame evidence is retained separately: proof1 failed at the float64-K/float32-points crop seam before a neural return/update; corrected proof2 performed two accepted private-head updates (versions 0→1→2), but its actual same-feature AMP head output was unchanged on both frames. Its three blocked cache probes remain recorded; the direct-refiner K dtype fix does not establish production-preprocessing equivalence. These short probes are not long-sequence accuracy evidence. The present full sequence supplies the actual changes above, including negative results.

This package contains only aggregate numbers and source hashes. Review independently recomputed statistics from saved errors and bound actual metadata; it did not reread GT, recompute geometry, or run a GPU. It is author-side independent-formula checking, not external replication.
