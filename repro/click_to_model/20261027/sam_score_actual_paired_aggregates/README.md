# Actual SAM-score mask-selection control

This package compares the original measured legacy-geometry runs with new measured SAM-score runs on the same development inputs and clicks. It retains all 16 cases, 5,642 planned input slots, 5,626 tracking slots, two unavailable static slots and the two original TLESS clicks without a unique declared-object mask hit. Actual complete trajectories are evaluated; earlier offline initialization alternatives do not replace a trajectory.

`paired_threshold_counts.csv` contains all 192 fixed scope/threshold comparisons and every correct/wrong/unknown transition. Negative deltas and unknowns are retained. Continuous MSSD/MSPD use the original symmetry-aware full-vertex functions, with 315/8/1 declared symmetry samples for bowl/wood/bleach. YCB-V all-frame values remain raw-GT diagnostics; the preselected 149 BOP tracking frames are separate. TLESS remains a small static pilot. Mustard uses the original 10,983 loader vertex rows and ADD <= 0.1 diameter, occlusion [100,130), and five consecutive correct post-reappearance inputs. Other main thresholds use strict <. Symmetry-sensitive ordinary ADD does not alone establish tracking failure or physical identity.

`initialization_identity_counts.csv` reports actual source-bound initialization comparisons. Equal SAM/candidate arrays do not imply identical selected output or trajectory. SAM scores are not identity probabilities. `sequence_timing.csv` separates initialization, instrumented frame tracking, child and parent timing. Frame tracking excludes per-frame journal rewrites; nested costs cannot be added twice. Loading/cache conditions are uncontrolled. Old wood parent timing remains null. Child/parent all-input throughput is not deployment FPS.

Zero admission conditional risk is null, never zero. No identity trust, held-out result, independent-frame confidence interval or causal speed claim is made. Two earlier CPU posthoc attempts are retained: v1 failed at NumPy-bool JSON writing; v2 completed but its mustard paired classification was invalid. Only corrected v3 tables enter this package. No GPU experiment was rerun for these posthoc fixes.

The independent review checks full aggregate/clock calculations using saved errors; it is not a new independent full-geometry recomputation. Source hashes are in `sources.json`. This package contains only aggregate numerical tables and descriptions: no raw pose/GT matrices, images, masks, models, weights, logs, code or absolute local paths.
