# 深度短暂缺失修复：本轮证据索引

本轮实现将可观察的 RGB 连续性与当前三维拟合分离。缺深度时仍禁止位姿发布和自适应更新；恢复后必须重新通过当前深度与原始锚点的检查。身份标志仍为未验证。

以下三个包按实际执行阶段排列。CPU 包中的“尚未 GPU 验证”是该阶段封存时的状态；随后两组 GPU 证据已经完成，不能把这个历史说明当作本轮最终状态。

| 阶段 | 结果 | 证据 |
|---|---|---|
| CPU 原版/候选对照 | 21 个双臂场景、126 个计划槽；包含预期 ID 失败及未执行槽 | [CPU 包](../native_depth_dropout_cpu/README.md) |
| 实际神经追踪与后验评价 | 两臂各 12 帧，仅第 4 帧深度置零；暂定发布从 4/12 到 11/12，缺深度帧无发布、无 private、无更新 | [实际与后验包](../native_depth_dropout_actual/README.md) |
| 完整版本普通 CLI 回归 | 原始 30 帧无深度干预；9,442 个科学数组逐字节一致，4 个 mask、发布决策与 native 汇总一致 | [完整版本包](../depthfix_complete_revision/README.md) |

新增发布的第 5–11 帧全部通过既定 21 项误差阈值；原版这些未发布候选也全部通过。因此主要收益是恢复有当前证据支持的输出覆盖。恢复段平均 ADD 从 2.001388 mm 到 1.995375 mm，变化很小，不能据此宣称显著精度提升。

这是一个已知合成开发片段上的固定深度故障实验，使用真实 SAM2、TAPNext 和 FoundationPose 调用。没有证明自然遮挡后的身份关联、周期纹理别名解决、广泛纹理/对称性泛化或 CVPR 水平。新完整版本的无 mesh 路径只做了 dry-run。所有实际失败、审计器修正与限制均保留；本次公开内容仅为数值、说明和来源哈希，不含新源码、原始位姿、GT 矩阵、图像或模型。
